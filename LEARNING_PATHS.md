# Learning paths

Each path links to existing library material and ends with a small artifact that can be reviewed
without claiming Studio execution. Run project-specific code in a separate test experience.

## Gameplay scripting

1. Read [[MOC-roblox-development]] and [[SRC-creator-hub-client-server]].
2. Study [[S-remote-event-telemetry-dashboard]] and the remote-event reference.
3. Practice: write a one-page server/client contract for a simple interaction, listing validation,
   ownership and failure behavior. Keep any code marked `Untested:` until executed.

## UI

1. Read [[MOC-ui-and-game-feel]] and [[R-responsive-matrix]].
2. Compare [[T-ui-pattern]] with the component recipes in the UI library.
3. Practice: sketch a responsive inventory panel with keyboard/gamepad focus, touch targets and
   empty/loading/error states; record a review checklist.

## Backend systems

1. Start with [[T-backend-systems-catalog]] and [[SRC-backend-platform-contracts]].
2. Read the data vault and purchase fulfillment contracts before choosing a persistence pattern.
3. Practice: make a failure table for one save operation, including retry, duplicate request,
   shutdown and recovery behavior. Leave live-service behavior unverified until tested.

## Horror design

1. Read [[MOC-horror-design]] and [[MOC-level-design]].
2. Study the adaptive director and pacing notes alongside the accessibility guidance.
3. Practice: outline a short route with three tension beats, one safe pause and a measurable
   playtest question. Label timing and player reactions as hypotheses until observed.

## Choosing a path

Start with the skill needed by the next playable milestone. Prerequisites in this vault are reading
order, not a formal course or certification.
