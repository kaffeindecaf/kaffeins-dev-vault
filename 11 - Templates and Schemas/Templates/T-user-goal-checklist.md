# User goal checklist

Track the user's stated outcomes for this project. Keep this file with the project, separate from
any shared-library roadmap.

## Goal format

```text
- [ ] **G-### — <clear outcome>** — Status: Not started | In progress | Blocked
  - Next: <one concrete action>
  - Done when: <observable evidence>
  - Updated: YYYY-MM-DD
```

Keep active entries when blocked, explain the blocker and next action, and move completed goals to
the completed section with delivery evidence.
