# v1.2.0 — Kaffeins Dev Vault

This release completes documentation and distribution work that does not need Roblox Studio.

## Added

- [[ONBOARDING_EXAMPLES]] demonstrates new-project, existing-project and skip-question flows.
- [[T-PROJECT-PROFILE]] and [[T-USER-GOAL-CHECKLIST]] are portable, generic templates.
- [[LEARNING_PATHS]] provides four routes with linked prerequisites and reviewable exercises.
- [[P-FICTIONAL-EXPEDITION-SLICE]] connects a server-authoritative mechanic, session data and UI
  states as an original design-only example.
- [[SOURCE_FRESHNESS_QUEUE]] tracks high-impact source review without claiming a current fetch.
- `scripts/release_audit.py` scans tracked files or a release ZIP for common private-data patterns.
- [[clean-workspace-review]] records manual onboarding and starter-link checks.

## Branding

The product display name is **Kaffeins Dev Vault** and the repository identity is
`kaffeins-dev-vault`. The CLI, README, home page and release metadata use the current v1.2.0 name.

## Verification scope

The workspace onboarding walkthrough is manual. CLI validation, index, generated navigation,
privacy scans and clean-clone quickstart are recorded in [[STATUS]] and the dated work log. The
fictional slice remains design-only and untested in Roblox Studio. UI runtime review, DataStore
integration and Creator Store candidate checks remain manual Studio follow-up in [[ROADMAP]].
