## Failures and corrections

- First validation pass found eight broken links; corrected targets and reran with zero warnings.
- Early audit patterns flagged generic policy wording, the auditor's own path-regex example and an
  intentional fake test credential. Narrowed patterns and documented the single fixture exception;
  final tree and ZIP both reported zero findings.
- `Get-FileHash` was unavailable through the shell wrapper; calculated the SHA-256 with Python's
  standard-library `hashlib` instead.
- The clean clone's first removal attempt hit Windows read-only Git pack files. Confirmed its path
  remained under ignored `exports/`, cleared the read-only attributes through Python's removal
  callback, and removed only that disposable clone.
