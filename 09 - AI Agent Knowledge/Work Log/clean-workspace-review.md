# Clean workspace onboarding and starter-link review

Manual offline review of onboarding and project starters. No Roblox Studio project was opened.

## Procedure and observations

- Copied `_PROJECT_TEMPLATE` into a disposable generic project folder under ignored `exports/`.
- Walked the new-project path: no profile found, so the first question distinguishes new from existing;
  confirmed answers are saved and unknowns stay unknown.
- Walked the existing-project path with a prewritten profile and goals: read those first and continue
  from the documented milestone; do not ask questions already answered.
- Walked the skip path: start the stated task, use available files, mark assumptions, and record only
  the user's explicit goal.
- Reviewed starter relative links after copying: shared-vault links and project-local templates are
  labeled separately. The profile/checklist templates added in this release contain placeholders,
  not example owner or game information.
- Disposable workspace removed after inspection; no project or imported source was edited.

## Limits

This is a manual documentation walkthrough, not an automated agent or Studio test. Re-run the link
review when starter files change.
