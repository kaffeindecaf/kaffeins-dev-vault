# Attachments

This folder holds local screenshots and media only when their provenance and reuse rights are
clear. The Roblox DataStore diagrams added in this vault remain embedded from Roblox's official
documentation rather than copied here; see [[SRC-roblox-data-store-player-profile]].

When adding a local attachment, record its source URL, capture date and applicable license or
permission status in the note that uses it. Do not put secrets, user data or unreviewed Creator
Store models here.
